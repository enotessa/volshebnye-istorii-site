Политика конфиденциальности

Приложение «Волшебные истории» может использовать технические данные, необходимые для работы приложения, восстановления доступа к контенту, обработки встроенных покупок, показа рекламы и ответа на обращения пользователей.

Какие данные могут использоваться

  • служебные идентификаторы приложения и установки;
  • данные, необходимые для встроенных покупок и временного открытия контента;
  • технические данные об устройстве и версии приложения для диагностики ошибок;
  • контактные данные, которые пользователь сам отправляет в поддержку.

Для чего используются данные

  • для работы основных функций приложения;
  • для восстановления купленного или временно открытого контента;
  • для показа и ограничения рекламных сценариев;
  • для улучшения стабильности и качества приложения.

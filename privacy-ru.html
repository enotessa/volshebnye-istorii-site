Политика конфиденциальности

Редакция от 18 сентября 2026 года

Мы используем только те данные, которые нужны для работы приложения, восстановления покупок, поддержки, безопасности, аналитики и показа рекламы в бесплатной версии. Полные реквизиты банковской карты разработчику не передаются.

1. Оператор данных

Оператором персональных данных является самозанятая Покаместова Анастасия Максимовна, ИНН 695205887530. Вопросы о данных можно направить на raccoon.app.labs@gmail.com.

2. Какие данные могут обрабатываться

  • адрес электронной почты, одноразовые коды и технические идентификаторы учётной записи;
  • сведения о приобретённой услуге, сумме, валюте, статусе и идентификаторе платежа;
  • состояние подписки, дата окончания оплаченного периода и признак автопродления;
  • IP-адрес, примерная страна, версия приложения, модель и версия операционной системы устройства;
  • события использования приложения, рекламные события, сведения о сбоях и диагностике;
  • содержание обращения в поддержку и предоставленные пользователем вложения.

Имя ребёнка, прогресс чтения, избранное и созданные родителем голосовые записи сохраняются на устройстве в пределах возможностей текущей версии Приложения. Разработчик не запрашивает у ребёнка самостоятельную регистрацию или оплату.

3. Для чего нужны данные

  • для подтверждения электронной почты и защиты учётной записи;
  • для проведения оплаты, выдачи чека и восстановления приобретённого доступа;
  • для управления подпиской, уведомления о продлении, отмены и возврата;
  • для защиты от злоупотреблений и повторных запросов;
  • для определения доступных способов оплаты по примерной стране;
  • для показа и ограничения рекламы в бесплатной версии;
  • для анализа востребованности функций, устранения ошибок и улучшения приложения;
  • для ответа на обращения пользователей и исполнения требований закона.

4. Основания обработки

Данные обрабатываются для заключения и исполнения договора с пользователем, на основании предоставленного согласия, для выполнения обязанностей Исполнителя по закону, а также для обеспечения безопасности и работоспособности сервиса в пределах, допускаемых законодательством.

5. Сервисы и получатели данных

Для работы отдельных функций могут использоваться:

  • Robokassa и иные показанные пользователю платёжные сервисы — для проведения платежей, возвратов и передачи статуса операции;
  • сервисы ФНС и фискализации — для формирования и передачи электронных чеков;
  • Yandex Cloud — для размещения серверной части, базы данных и цифрового контента;
  • почтовый провайдер — для кодов входа, чеков и уведомлений о подписке;
  • myTracker — для обезличенной продуктовой аналитики;
  • рекламные сервисы, используемые в соответствующей сборке Приложения, — для показа и измерения рекламы;
  • DB-IP — для приблизительного определения страны по IP-адресу.

Состав сервисов может различаться в зависимости от версии и канала распространения Приложения. Платёжные реквизиты карты пользователь вводит на защищённой стороне платёжного сервиса; разработчик не получает и не хранит полный номер карты, срок действия и CVC/CVV.

6. Срок хранения и защита

Данные хранятся не дольше, чем это необходимо для указанных целей, восстановления приобретённого доступа, разрешения споров и выполнения требований налогового, бухгалтерского и иного законодательства. Срок хранения отдельных технических журналов может быть короче.

Используются разграничение доступа, защищённые соединения, серверная проверка платежей и иные разумные организационные и технические меры. При этом ни один способ передачи и хранения данных не может гарантировать абсолютную защиту.

7. Права пользователя

Пользователь может запросить сведения об обработке, исправление, ограничение или удаление данных, отозвать согласие либо возразить против обработки в случаях, предусмотренных законом. Для обращения напишите на raccoon.app.labs@gmail.com. Для защиты учётной записи может потребоваться подтверждение владения связанной электронной почтой.

Удаление данных не затрагивает сведения, которые Исполнитель обязан хранить по закону, и может сделать невозможным восстановление ранее приобретённого доступа, если иной способ подтверждения покупки отсутствует.
